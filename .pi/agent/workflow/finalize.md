# Finalize

Input: plan path plus notes with report paths. Tidy the task's docs, then stop. No journal, and no question or hint about what comes next.

1. **Inputs.** Read the whole plan (given a report, resolve its plan through its references; ask only if it's missing or ambiguous). Fix the exact set of this task's artifacts: plan, clarifications, progress, review, blocker and UI feedback reports, from links and notes, plus reports in `~/.pi/reviews/<key>/` named for this task id. Read them completely. Include review evidence manifests only through report references: read each and verify same-task membership and identity (canonical task root, kind, scope/exclusions and revision against its report); filename alone is not proof. Unclear/shared membership, unreadable or conflicting evidence → pause and delete nothing. Evidence is not semantic approval.
2. **Write** the plan over with a concise standalone decision record: the task, final choices with their documented reasons, rejected alternatives only when they explain a choice, accepted limitations and deferred findings with reasons. No checklists, routing, review ceremony, raw test output, or links to files being deleted. Don't invent rationale or call unresolved findings fixed.
3. **Verify, then delete.** Read the summary back and check the sources' decisions and reasons are represented. Only then delete the other identified, fully consolidated, unshared artifacts, including the verified referenced evidence manifests; preserve final decisions and evidence limitations in the summary. Failure → delete nothing. Never delete the summary, directories, source files or anything outside the identified set.
4. **Report** the summary path and what was deleted (or what remains), then call `workflow_exit`.
